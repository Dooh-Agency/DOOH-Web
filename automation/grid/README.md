# Tandas de contenido

Crear una carpeta por tanda con el formato `YYYY-MM-DD` (lunes de generación). Ejemplo:

```text
2026-08-24/
  grilla.md
  copy_01.md
  direccion_creativa_01.md
  grafica_01.png
  story_01.png
  qa_01.md
```

El archivo `grilla.md` se inicia desde `PLANTILLA_GRILLA.md`. Cada caption usa el formato `[ES]` seguido por `[EN]` dentro del mismo archivo y post.

Cada tema contiene una pieza principal y una story de Instagram asociada, publicada el día calendario posterior. La grilla local y el Google Sheet registran ambos assets, sus horarios y sus estados.

Cuando una pieza deriva de una nota de blog, completar `Nota fuente / URL` con el título de trabajo o la URL publicada. La adaptación debe desarrollar un ángulo propio y dirigir a la nota; no reutilizar el texto del artículo como caption.

El `Aprobado` de cualquiera de los responsables definidos por DOOH valida la pieza, pero no publica por sí solo. No programar ni publicar sin asset final, fecha/hora definida y `Programar publicación = Sí`.
